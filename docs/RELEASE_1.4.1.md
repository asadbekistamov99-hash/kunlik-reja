# Jarvis Ultra 1.4.1

- Automatic wake mode now requires the two-word **Hey Jarvis** phrase.
- Instagram opening is resolved to the Instagram package instead of similarly named apps.
- Recent call count phrases such as “oxirgi qo‘ng‘iroqlardan 3 tasini ayt” are handled as call history.
- “Ilovadan chiq” and related commands return to the Home screen.
- Selected Gemini/OpenAI voice does not silently fall back to the device voice.
- Includes Jarvis Ultra neon dashboard and all 1.4.0 features.
